현재 `src/profile.ts`는 가스기능사의 일반적으로 알려진 필기 형식을 **학습용 가정**으로 분리한다:

객관식 4지선다 60문항, 60분, 100점 만점 환산 60점 이상, 과락 없음.

해당 법정 수치에 대한 암기 문제를 작성하지 않았다.

## 문제은행과 권리

| 구분 | 가스일반 | 가스장치 및 기기 | 가스안전관리 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 개념 자체 제작 | 20 | 20 | 20 | 60 |
| 계산 조건 변형 | 316 | 312 | 312 | 940 |
| 내부 검수 등록 | 336 | 332 | 332 | 1000 |
| 원문 기출 | 0 | 0 | 0 | 0 |
| 복원 | 0 | 0 | 0 | 0 |

기본 JSON의 실제 고유 ID 수와 정규화 본문·정렬 보기 지문 수 모두 1,000이다.
검증 대기 0, 제외 0, 사용자 등록분 0이며 등록 수 기준 부족 수는 0이다.
단, 1,000개의 독립 개념이나 기출을 뜻하지 않는다. 계산은 24개 family의 940개 숫자 변형이다.
첫 4유형은 40개씩, 나머지 20유형은 39개씩이다. 독립 학습 단위는 개념 문항 60개와
계산 유형 24개로 총 84개이다. 같은 family의 문장 구조·풀이 방법은 반복된다.
일부 변형은 입력이 달라도 같은 정답을 갖는다. 이를 의미상 독립 유형으로 세지 않는다.
기본 모의시험은 영역별 family를 우선 하나씩 뽑고, 부족할 경우에만 다른 고유 ID로 보충한다.
현재 영역별 개념 20개와 계산 8유형으로 20개 선택이 가능하여 기본 은행에서는 family 중복이 없다.

모든 문항은 AI의 일반적인 물리·가스 기초 지식을 바탕으로 이번 저장소에서 자체 작성했다.
외부 교재·기출 사이트의 문제를 복사하지 않았다. 실제 기출의 원문·회차·재배포 허락은
확보하지 못했으므로 기출·복원 수는 0이고 모든 year/session은 null이다.
sourceUrl은 작성 저장소를 나타낼 뿐 외부 정답 증빙이 아니다.
새 문항과 양식은 CC BY 4.0, 귀속은 Craftsman-Gas-CBT contributors이며 저장소 URL을 함께 표기한다.
코드는 원본 MIT 저작권 고지를 보존한다. 외부에 있는 문제의 이용 권리까지 부여하지 않는다.

## 내부 검수의 범위와 한계

- 60개 개념 원고의 질문·정답·해설을 읽고 일반 원리에 비추어 내부 검토했다. 오답 선택지는 명확히 구별되도록 작성했다.
- 계산 생성은 Python Decimal, 재계산은 별도 TypeScript 물리 관계식으로 수행한다. 입력·단위·반올림·정답 위치·수치 동치 보기·해설 결과를 검사한다.
- 결정적 ID·순서와 재생성 일치를 검사한다. ID 중복, 공백 정규화 및 보기 재배치 중복을 차단한다.
- 의미상 반복은 family로 묶고 계산 유형별로 공개한다. 전 문항의 외부 전문가 의미 검수, 독립 인간 편집 검수, 공식 출제기준 대조는 수행하지 않았다.
- 따라서 `reviewed`는 위 내부 검토의 완료를 뜻한다. 전문가 검수나 공식 승인 표시는 아니다.
- 기초 계산에 편중되어 실제 시험 전 범위·난이도·빈도·법규 대비를 충족한다고 보증하지 않는다. 숫자 변형 940개를 가리는 방식으로 수량을 보고하지 않는다.
- 환기·혼합·물질수지 문항은 문제에서 명시한 이상 가정 계산이며 실제 누출·밀폐공간 출입의 안전 판단이나 작업 지침이 아니다.

## 검증 실행

작업 디렉터리: `/workspace/Craftsman-Gas-CBT`.
Node v24.19.0 / npm 11.9.0. `npm ci`는 lockfile 변경 없이 완료했다.
단위 검사: `npm test`, 프로덕션 빌드: `npm run build`.
브라우저: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`.
최종 결과: 단위 959개 통과; 브라우저 24개 통과·모바일 전용 데스크톱 중복 4개 제외; 타입 검사·프로덕션 빌드 종료 코드 0. 개발 서버 HTTP 200 및 HTML 제목 확인. Vite 청크 크기 경고는 남는다. 최종 결과와 남은 한계는 README의 실행 결과에도 기록한다.

브라우저 검사는 PC Chrome과 Pixel 7의 Chromium 에뮬레이션이다. 실기기·Safari·Firefox는 미실행이다.
390×480 / 740×360에서 wheel과 Chromium CDP touch 입력을 구분해 수행한다.
`scrollTop`은 관찰에만 사용하며 프로그램으로 변경하지 않는다.
하단 백업 다운로드·초기화 확인창, 위로 복귀 후 대시보드 선택까지 검사한다.
글자 크기를 확대한 메뉴도 휠 입력으로 검사한다.
자동 브라우저 검사는 실기기 인증을 대신하지 않는다.
