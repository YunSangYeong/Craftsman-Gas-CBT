# 가스기능사 필기 CBT

전기기능사 CBT의 화면·학습 기능을 재사용한 비공식 가스기능사 학습 앱입니다.
대시보드, 실전 모의시험, 랜덤 문제풀이, 해설, 오답노트, 북마크, 통계,
JSON/CSV 로컬 등록·검수·내보내기, 기록 백업·초기화를 제공합니다.
로그인과 서버 없이 현재 브라우저에 저장합니다.

최신 표준 **v1.4.0**을 [AGENTS.md](AGENTS.md)에 연결하고 스킬 폴더 전체를 보존했습니다.
학습 기준 선택 메뉴와 상단 상시 안내 배너는 없습니다. 저장 오류 경고는 유지합니다.
실전은 답안 선택 후, 랜덤은 채점 후 **Space**로 다음 문제로 이동합니다.
마지막 실전 문항에서 Space는 제출하지 않습니다.
모바일 메뉴는 작은 높이와 가로 모드에서도 독립적으로 스크롤합니다.

## 규칙과 자료 확인 상태

Q-Net 공식 자료 요청은 프록시 `403 Forbidden`으로 차단되었습니다.
**시험 규칙의 공식 확인은 미완료**이며 공식 시험을 검증하여 재현한 서비스가 아닙니다.
현재 학습 설정은 4지선다 60문항·60분·동일 배점·60점 이상·과락 없음입니다.
미응답은 오답이며 합격 판정은 반올림 전 비율을 사용합니다.
가스일반 / 가스장치 및 기기 / 가스안전관리 각 20문항은 학습용 균등 배분으로
공식 과목별 출제 비율을 뜻하지 않습니다. 설정과 확인 상태는 [profile.ts](src/profile.ts)에 분리했습니다.
공식 확인 대상은 [Q-Net 종목 상세](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=6335)입니다.

[기본 문제은행](src/data/questions.json)은 중복 제거 후 내부 검수 1,000문항입니다.

| 유형 | 가스일반 | 가스장치 및 기기 | 가스안전관리 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 자체 제작 개념형 | 20 | 20 | 20 | 60 |
| 자체 제작 숫자 변형 | 316 | 312 | 312 | 940 |
| 등록 합계 | 336 | 332 | 332 | **1000** |

원문 기출 0, 복원 0, 검증 대기 0, 등록 수 기준 부족 0입니다.
숫자 변형은 **24유형 940개**이며 독립 개념형 60개와 구별합니다.
1,000개 기출 또는 독립 개념을 확보한 것은 아닙니다.
출제 연도·회차는 전부 null입니다. AI 일반 지식으로 자체 작성했고 기출 원문을 복제하지 않았습니다.
CC BY 4.0으로 사용 가능하며 Craftsman-Gas-CBT contributors와 저장소 URL을 표시합니다.
재사용 코드의 MIT 고지도 [LICENSE](LICENSE)에 보존했습니다.

내부 문장·정답 검토와 별도 수치 재계산을 수행했습니다.
**외부 전문가 검수·공식 출제기준 대조·법규 최신 판 확인은 미완료**입니다.
기초 개념과 계산 중심 자료로 실제 시험 전 범위와 난이도를 보증하지 않습니다.
출처 확인 범위, 계산 가정, family 반복·중복 정책은 [검증 기록](docs/verification.md)에 공개했습니다.

## 개발과 검증

Node 24.19.0, npm 11.9.0에서 확인했습니다. 다른 런타임은 package engines를 확인하세요.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

환경에 이미 Chromium이 있으면 다운로드 대신 다음 명령을 사용합니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

프로덕션 base는 `/Craftsman-Gas-CBT/`입니다. 문제은행 재생성은
`python3 scripts/generate_bank.py`이며 [개념 원고](scripts/concepts.json)와 함께 버전 관리합니다.
일반 개발에 재생성은 필요하지 않습니다. 동일 원고·코드에서 동일 JSON을 생성합니다.

최종 로컬 검증 결과(2026-11-03):

- `npm ci`: 성공, lockfile에 따른 110개 패키지 설치.
- `npm test`: 2개 파일, **959개 통과**, 실패 0, 종료 코드 0.
- `npm run test:e2e`: 타입 검사·프로덕션 빌드 성공, **24개 통과 / 4개 의도적 제외**, 실패 0, 종료 코드 0. 제외 4개는 모바일 전용 메뉴 검사의 데스크톱 중복 실행이다.
- 실제 Space keydown/keyup, 답안·복원·자동 제출·결과·오답·북마크·통계·등록·초기화·손상 원본 보존을 PC와 Pixel 7 에뮬레이션에서 확인했다.
- 390×480과 740×360 메뉴의 휠·native touchStart/move/end 입력, 백업 다운로드·초기화 확인창·상단 대시보드 복귀를 확인했다. 글자 확대 메뉴도 검사했다.
- PC·모바일 대시보드와 문제 화면 스크린샷을 직접 확인했다. 실기기·Safari·Firefox·실제 블로그 iframe은 미실행이다.
- 개발 서버 시작 지침을 실행하고 HTTP 200 및 HTML의 가스기능사 제목을 확인했다.
- 빌드 JS는 약 1.59 MB(압축 약 144 KB)이며 Vite의 500 KB 청크 크기 경고가 남는다. 오류는 아니다.
- 생성 재현성·문항별 독립 계산·유형별 집계와 중복 검사가 통과했다. 스킬 폴더 9개 파일의 원본 일치도 확인했다.

초기 로컬 검사에서 누락한 Vitest 설정을 복사했고, 생성 문구 공백을 통일했다.
터치 합성 제스처가 스크롤을 발생시키지 않아 native touchStart/move/end로 입력 경로를 수정한 뒤
메뉴 검사를 다시 통과했다. 이들은 로컬 검사 수정이며 배포 재시도가 아니다.

## 기록과 개인정보

저장 namespace는 `Craftsman-Gas-CBT:v1`이며 다른 자격증과 분리합니다.
최근 응답 5,000개, 시험 결과 30회를 보관합니다. 진행 중 시험·랜덤 세션·오답·북마크·로컬 문항도 저장합니다.
시험은 절대 종료 시각으로 저장하여 새로고침·백그라운드 전환으로 시간이 늘지 않습니다.
손상 원본을 자동 덮어쓰지 않으며 저장 실패는 경고합니다.
백업은 JSON 다운로드이고 **백업 UI 복원 기능은 없습니다**.
가져온 문항은 검증 대기로 이 브라우저에만 등록되며 공용 은행에 자동 게시되지 않습니다.
시크릿 모드·iframe·저장 제한·브라우저/origin 변경에 따라 기록이 분리되거나 저장이 제한될 수 있습니다.

## GitHub와 Pages

준비한 workflow는 main push → 단위/PC·모바일 검사 → Pages 자동 배포입니다.
PR은 검증만 수행하고 deploy는 main으로 제한합니다. 자동 재시도는 없습니다.

이번 작업에서는 **배포 사전 확인의 첫 GitHub API 요청이 프록시 403으로 차단**되어
정책에 따라 중단했습니다. main 푸시·CI·Pages 배포·공개 화면 확인은 수행하지 않았습니다.
대체 배포나 두 번째 시도를 하지 않습니다. 코드는 배포를 유발하지 않는 별도 브랜치로 보존합니다.
예상 URL: https://YunSangYeong.github.io/Craftsman-Gas-CBT/ — 배포 성공 또는 공개 확인을 뜻하지 않습니다.
지금 필요한 최소 조치는 환경 네트워크 허용 목록에 `api.github.com` 추가입니다.
Pages 최초 설정과 승인 필요 여부는 API 차단 때문에 확인하지 못했습니다.
이후 마무리는 사용자가 직접 진행합니다.


코드 보존 브랜치: `codex/gas-cbt-20261103`.
정확한 최종 커밋은 해당 브랜치의 `git log -1`과 작업 완료 보고에서 확인한다.
이 브랜치는 main push 트리거와 일치하지 않으며 PR이나 workflow 수동 실행을 만들지 않는다.
클라우드 환경 초안에 `install_script`(npm ci)와 `start_skill`(실행·검증·차단 상태)을 저장했다.
이는 현재 인스턴스의 실행 검증과 별개이며, 새 작업 재현을 활성화하려면 환경 설정에서 검토·저장한 뒤 Publish해야 한다.
GitHub Pages 공개 배포와 클라우드 환경 Publish는 서로 다른 작업이다.
